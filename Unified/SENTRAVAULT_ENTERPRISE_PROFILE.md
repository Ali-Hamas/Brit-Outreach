## 3. Licensing Style — Terms

- **License grant:** Non-exclusive, non-transferable subscription per named user (device-scoped identity). One user = one named human, unlimited devices via email/pass + safe code.
- **Term:** 12 months from order form, auto-renew for 12-month periods unless 60 days notice.
- **Billing:** Annually upfront (default). Monthly available at +15%. Setup billed on order form (instalments allowed for Vendor tiers). Net 30. Overages invoiced monthly.
- **Storage:** Pooled per tenant, soft limit with 7-day grace, then overage rate. No data loss on overage, only admin warning.
- **Data residency:** EU (UK/EU VPS) by default. Enterprise can choose private cloud / on-prem (data never leaves customer VPC).
- **Zero-knowledge:** Server holds only ciphertext + salted hashes of password/safe code. Customer holds keys derived from safe code. Breach does not expose plaintext.
- **Support & SLA:** Per tier table above. SLA credits: 10% for 99.0-99.5%, 25% below 99.0%.
- **DPA & Compliance:** Standard DPA included (Business+), custom DPA for Enterprise. GDPR, NHS DSP Toolkit/DTAC, FCA, eIDAS 2.0 alignment docs provided. Audit logs retained per tier (1yr Team, 3yr Business, 7yr Enterprise).
- **Termination:** 30-day cure for breach, 60-day non-renewal notice. Data export (encrypted) + 30-day deletion window.
- **Channel:** info@ascentraconsulting.co.uk | CRM: `mcp_ascentra_main / cat_sentravault`
- **Proof handling (UKHSA):** Never disclose identity. Use phrasing: "Trusted by consultants advising UKHSA" / "UKHSA-linked consultancy (private)" with anonymized logo.
