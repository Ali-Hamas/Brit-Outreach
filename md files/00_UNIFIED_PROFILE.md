- Biometric-only sign-up like "Sign up with Google" — unique identity number generated **single-device only** via on-device biometric

- Safe code: user-generated from app/system, **never stored in plaintext in system**, only a salted hash kept for verification; maintains GDPR
- Server has everything **encrypted** so breach does not affect user
- Lucrative for **EU market** — eIDAS 2.0 alignment, GDPR-native, vendor-neutral alternative to big-tech login
- Free early-access campaign for traction

### 4. Sentrivault — Cybersecurity Product (separate from Biometric Sign Up)
